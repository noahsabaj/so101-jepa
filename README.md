# so101-jepa

Written in ASD-STE100 (Simplified Technical English).

Research: an SO-101 arm learns to assemble another SO-101 arm. A hierarchical JEPA world model
(H-JEPA) and a planner control the arm. There is no VLA.

- [PLAN.md](PLAN.md): the north star, the rules, the architecture, the assumptions, the ladder,
  the phases and every result.
- Related: [H-JEPA fork](https://github.com/noahsabaj/H-JEPA) and the earlier skunkworks project
  (WidowX AI, frozen V-JEPA 2.1).

Status: Phase 0 (sim only).
